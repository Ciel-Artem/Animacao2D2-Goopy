# Animacao2D2-Goopy


Idle- O personagem ficara parado com uma mão no bolso, ele fara movimento de up and down

Idle- O personagem fica de uma forma semi-derretida, quase como um sorvete derretendo no sol

Ataque- O personagem bota seu braço para trás, seu punho cresce de tamanho e então o personagem desfere um golpe com seu punho aumentado

Pulo- As pernas do personagem diminuem, como molas ganahndo pressão, o personagem então é jogado para cima com altas velocidades

Receber dano- O personagem vai para trás com sua cintura indo primeiro, como se tivesse sido golpado fortemente

morrer-  O personagem começa a derreter e então vira uma poça de gosma negra no chão
